# Figure captions — Revision 4.1

**Figure 1. Core programmed-agent profiles.** The displayed radar coordinates use the original plotting normalization and summarize the core simulation. They are descriptive profiles, not estimates of a universal capability geometry. Memorizer and Compositional agents share the realized base channel by construction; specialized-channel responses differ. Table 1 and S1 supply unnormalized values and uncertainty companions.

**Figure 2. Subject-specific BCI information rate and threshold sensitivity.** The primary fixed-window decoder is plotted by subject with descriptive uncertainty intervals. The threshold panel summarizes V_eff counts under the prespecified F1/support rule. No pooled confusion matrix or historical fold-ratio claim is used. Individual threshold curves for both decoders are provided in S8e; error bars do not establish between-subject significance.

**Figure 3. Matched-base comparison.** Identical realized base observations are used within each Memorizer/Compositional pair. Aggregate accuracy over base plus compositional trials compresses the larger held-out difference because held-out trials contribute only part of that aggregate. The panel does not show equal aggregate accuracy or an empirical discovery of base equality.

**Figure 4. Primary-decoder confusion matrices.** Row-normalized evaluation confusion matrices for all nine subject-specific T-to-E systems. Rows are true classes and columns are predictions. Trial counts after organizer artifact exclusion are reported in Table 3a and S8c. Class order is left hand, right hand, feet, tongue.

**Figure 5. Metric-specific rejection probabilities.** Cell values summarize the original 1,000-replication power experiments; the zero-effect row is empirical size, not power under an alternative. C2, R, and B_min axes give trial counts per system, while the U axis gives total uncertainty trials. The B_min panel uses the system-label permutation test. Tables 2a–2e and S7 report effects, assumptions, and Monte Carlo intervals.

**Figure S8. FBCSP-style confusion matrices.** Row-normalized confusion matrices from the stronger decoder on the same retained evaluation trials, with the same class order as Figure 4. This is a robustness analysis, not an exact reproduction of Ang et al.'s temporal competition pipeline.
